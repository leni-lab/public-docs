# Public Docs

Public user documentation for TIUS applications.

## Purpose

This repository contains published, user-facing documentation exported from
application source repositories.

## Applications

- [sftpbeam](apps/sftpbeam)
- [wikiread](apps/wikiread)

## Versioning

Documentation is published per application version.
Each release is stored in its own version directory, for example:
`apps/sftpbeam/26.03/`.

## Source of Truth

The source of each document lives in the corresponding application repository.
Do not edit exported files manually in this repository.
