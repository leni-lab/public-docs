# leniextract

leniextract reads a LENI export and returns selected information as JSON.
It can be used on its own or by applications such as storeindex.

Available fields include identity, transmission time, selection metadata, and
the article content needed by formatters. LENI Markdown is separated into
article body, editorial metadata, agency footer, and service information.
Read an export from a named file or provide it through standard input.
