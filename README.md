# User Docs

User documentation for leni-lab applications.

## Purpose

This repository contains published, user-facing documentation exported from
application source repositories.

## Applications

config management

- [configtrack](apps/configtrack)
- [configview](apps/configview)
- [configview-usermgr](apps/configview-usermgr)
- [wikipush](apps/wikipush)
- [wikiread](apps/wikiread)
- [wiki2config](apps/wiki2config)
- [wiki2config-usermgr](apps/wiki2config-usermgr)

news item store
  
- [leni2store](apps/leni2store)
- [leniextract](apps/leniextract)
- [storeindex](apps/storepack)
- [storepack](apps/storepack)

general utilities

- [logarchive](apps/logarchive)
- [sftpbeam](apps/sftpbeam)

## Versioning

Documentation is published per application version.
Each release is stored in its own version directory, for example:
`apps/sftpbeam/26.03/`.

## Source of Truth

The source of each document lives in the corresponding application repository.
Do not edit exported files manually in this repository.
