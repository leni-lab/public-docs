# runtime settings

| section | key | default | values |
| --- | --- | --- | --- |
| `[app]` | `max_runtime` | *(none)* | duration, e.g. `8h`, `30min` |

`--max-runtime` CLI option overrides the config value.

for duration syntax see [../fields/syntax.md](../fields/syntax.md).
